# McPacks by deenpro1
This is an open resource pack database, made by me. Of you want your pack added or found a bug, open an issue.

## 1. Adding a pack:
To add a pack, open an issue listing:
    1. Name
    2. Description
    3. Version
	4. Download Link
> [!CAUTION] 
> Illegal or 18+ resource packs won't be accepted.

If you don't have a download link, upload the file in the issue or over mediafire.

## 2. Contributing
If you want to contribute, fork the newest version of the main branch. Then create a pull request containing all changes as well as a reason why I should accept the pull request. You will be thanked in the website as developer. 
> If it's not a minor change, I won't list you on the site.
More about contribution will be added in the future
